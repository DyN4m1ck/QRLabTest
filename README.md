# QRLab

Приложение Avalonia для генерации QR-кодов и штрихкодов и исследования устойчивости к искажениям. Три экрана: генерация, мутации и считывание.

```powershell
dotnet run --project QRLab.View
dotnet test QRLab.sln
```

## Генерация

Поддерживаются QR, EAN-13, Code 128 и PDF417. Можно создать один код или пакет, задать размеры изображения, тихую зону и содержимое. В режиме шаблона `{num}` заменяется номером с минимум четырьмя цифрами; произвольный текст сохраняется буквально.

Класс размера QR: `0` — автоматический выбор, `1–40` — фиксированная версия (21×21…177×177 модулей без тихой зоны). Доступны уровни коррекции L/M/Q/H. Если содержимое не помещается, генерация отклоняется.

EAN-13 принимает 12 ASCII-цифр с вычислением контрольной либо 13 цифр с проверкой контрольной суммы. Ошибка любого образца отменяет весь пакет, сохраняя предыдущий набор.

Генератор сразу создаёт готовые PNG заданной ширины и высоты. SkiaSharp растеризует результат ZXing.Net с целочисленным масштабом, без сглаживания. Двумерные коды сохраняют пропорции и центрируются на белом фоне. Матрицы ZXing остаются внутренней деталью кодировщика; модели Core, ViewModels, превью и хранилище работают с `RasterImage`.

## Мутации

Гауссово размытие работает с пикселями исходного изображения через фильтр SkiaSharp. Параметр σ задаётся в пикселях; при σ = 0 возвращается исходное изображение.

Кляксы, ластик и перспектива пока сохраняют изображение без изменений. Для них оставлены отдельные модели параметров и реализации мутаций. Чтобы добавить обработку, достаточно реализовать соответствующий `ImageMutation<TOptions>`; UI и хранилище не требуют изменения.

Цепочка применяется последовательно: каждый кадр использует результат предыдущего. Изменение ранней операции пересчитывает последующие кадры. Исходник остаётся неизменным; доступны выбор кадра, отмена, повтор, сброс и применение цепочки ко всему набору. Колесо масштабирует превью, инструмент «Рука» перемещает изображение.

## Сохранение наборов

Единственный формат изображения — PNG. «Сохранить набор» записывает уже существующие PNG-данные оригиналов и кадров побайтно, без повторной генерации, растеризации или перекодирования. Неизменённые кадры используют один файл изображения.

В папке находятся изображения и `qrlab-set.json` с параметрами генерации и историей мутаций. Для сохранения выберите новую или пустую папку; существующие файлы не перезаписываются. Название набора — имя папки.

«Открыть набор» → выберите папку → «Загрузить из папки». Изображения и кадры загружаются из файлов без повторного выполнения операций. Папку можно переносить и переименовывать. Старые матричные форматы наборов не поддерживаются.

## Считывание

Результаты распознавания и статистика пока демонстрационные. Поиск, фильтрация и выбор образца работают; выбранный образец можно открыть в редакторе мутаций.

## Структура

- `QRLab.Core/Models/Generation` — иерархия параметров кодов, общие значения по умолчанию и ограничения.
- `QRLab.Core/Models/Images` — неизменяемые данные PNG, без зависимости от Avalonia или SkiaSharp.
- `QRLab.Core/Models/Mutations` — типизированные параметры операций и растровые кадры.
- `QRLab.Core/Interfaces` — отдельные контракты генератора, мутаций, хранилища и распознавания.
- `QRLab.Image/Generation` — кодирование ZXing.Net и однократная растеризация в PNG.
- `QRLab.Image/Mutations` — расширяемый конвейер и реализации операций.
- `QRLab.Image/Storage` — запись готовых изображений и чтение наборов.
- `QRLab.View/Controls/RasterPreview.cs` — показ готового изображения и жесты. Декодирование для экрана не изменяет PNG-данные.
- `QRLab.View/Presentation` — объекты вариантов выбора с enum-значением, русской подписью и иконкой.
- `QRLab.View/App.axaml.cs` — точка сборки приложения; ViewModels зависят от контрактов Core.
